# Deep Learning Interview Preparation Notes

Comprehensive notes covering deep learning fundamentals, computer vision, and generative models.

## 📚 Contents

### Part 1: Foundations
- Neural Networks and Optimization
- Generalization and Learning Theory

### Part 2: Computer Vision
- Convolutional Neural Networks
- Object Detection and Segmentation
- Vision Transformers
- Self-Supervised Learning

### Part 3: Generative Models
- Variational Autoencoders (VAEs)
- Generative Adversarial Networks (GANs)
- Diffusion Models

## 🚀 Building the Book

This book is built using [Quarto](https://quarto.org/).

### Prerequisites
- Quarto (>= 1.3)
- Python (>= 3.8) or R (>= 4.0)

### Build Commands
```bash
# Preview locally (auto-refresh)
quarto preview

# Render to HTML
quarto render

# Render specific format
quarto render --to pdf
```
